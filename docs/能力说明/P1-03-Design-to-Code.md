# P1-03 Design-to-Code

## 定位

把设计输入转为可追溯、可复用且可验证的项目代码，而不是一次性生成视觉文本。

## 当前交付

- [Design-to-Code 框架](../../frameworks/design-to-code/README.md)与 Contract Validator：`reference-implemented`；
- [`design-to-code` Skill](../../skills/design-to-code/SKILL.md)：`usable`；
- Schema、模板、程序测试和行为案例。

契约固定设计来源与版本、Frame、目标路径、现有组件复用、响应式、状态、交互和无障碍要求。`validated` 必须同时有视觉和行为 Evidence。

## 当前边界

设计理解、审美判断和实现仍由 Agent/维护者负责；设计平台读取、资产下载、视觉差异和浏览器验证由采用方 Adapter 提供。只有截图或版本不明时最多输出 `partial`。
