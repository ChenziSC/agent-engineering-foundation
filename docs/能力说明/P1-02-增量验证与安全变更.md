# P1-02 增量验证与安全变更

## 定位

把变更路径、消费者风险、自动检查、浏览器关键场景、人工门禁、Evidence 和回滚条件组织成显式矩阵，防止局部检查被误写成整体安全。

## 当前交付

- [增量覆盖与浏览器验证框架](../../frameworks/change-validation/README.md)：`reference-implemented`；
- [`safe-change` Skill](../../skills/safe-change/SKILL.md)：`usable`；
- JSON Schema、模板、Validator、合成测试和行为案例。

程序检查路径是否被规则覆盖、必需结果是否通过且有 Evidence。Agent 负责识别消费者和风险；真实 Coverage、Browser 与 CI 由采用方 Adapter 采集。没有版本一致的 Evidence 时不得输出 `validated`。

## 当前边界

- 不自动执行提交、推送、发布或不可逆迁移；
- 不自动证明覆盖规则足以代表全部业务风险；
- 不用路径筛选隐藏候选中的其他变更；
- Browser Scenario 契约已实现，真实浏览器执行器未内置。
