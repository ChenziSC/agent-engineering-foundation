# 组件准入检查清单

## 候选与复用

- [ ] 已搜索页面、应用、项目共享和基础组件来源。
- [ ] 已记录搜索范围、关键词和候选证据。
- [ ] 已比较近似组件的语义、状态、API、依赖和调用方。
- [ ] 已解释为什么 `reuse`、`wrap` 或 `extend` 不足。

## 放置层级

- [ ] 至少有两个独立、可核实的复用场景，或明确选择留在本地。
- [ ] 组件提供稳定 UI 能力，而不是一次性业务编排。
- [ ] 公开 API 不绑定单一页面的数据结构、权限或路由。
- [ ] 依赖、样式和运行时可被目标消费方正确加载。

## 标准层交付

- [ ] Registry 已登记稳定标识、位置、层级、状态和 Contract。
- [ ] Contract 说明用途、边界、公开 API、状态、依赖和验证。
- [ ] 组件从稳定入口导出，消费方不依赖内部路径。
- [ ] 验证类型与组件风险匹配。
- [ ] 维护责任、兼容承诺和废弃方式明确。

## 迁移与发布

- [ ] 已扫描调用方和深路径引用。
- [ ] 已识别默认值、DOM、状态和依赖变化。
- [ ] 已定义迁移窗口、回滚条件和完成标准。
- [ ] 破坏性变更、删除和发布已获得必要确认。
