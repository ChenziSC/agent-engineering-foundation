# AI 友好仓库人工检查清单

## 根规则

- [ ] 只包含全仓不变量、模块地图、验证方式和安全边界。
- [ ] 没有当前任务进度或聊天摘要。
- [ ] 没有复制模块级细节。
- [ ] 所有命令和路径真实存在，或明确标为示例。

## 模块规则

- [ ] 只在规则密集且稳定的模块存在。
- [ ] 适用目录清晰。
- [ ] 不重复根规则。
- [ ] 稳定入口和验证方式仍然有效。

## 长期知识

- [ ] 每个条目有 ID、范围、状态和最后复核日期。
- [ ] 稳定事实有权威来源。
- [ ] 推断没有伪装成事实。
- [ ] 没有当前任务状态、真实凭证、个人信息或生产数据。
- [ ] 刷新条件明确。

## Registry

- [ ] Registry 中的路径存在。
- [ ] ID 唯一。
- [ ] retired 条目不会被默认加载。
- [ ] review-required 条目有明确提示。
- [ ] 知识范围没有被无条件扩大。

## 代码入口映射

- [ ] 每种高频任务都有最小起始路径。
- [ ] 模块规则和知识引用存在。
- [ ] 默认排除目录不会隐藏必要上下文。
- [ ] 不把所有文档无差别加入上下文。

## 当前交付状态

- [ ] 当前任务状态保存在 Specflow 或等价产物中。
- [ ] 长期知识只保存当前事项的引用，不复制状态。
- [ ] 没有两套相互冲突的 Active 状态。

## 冲突与过期

- [ ] 同一规则只有一个权威来源。
- [ ] 冲突规则已经明确范围，未被静默合并。
- [ ] 代码入口变化后相关知识已标记复核。
- [ ] 过期内容先标记，不自动删除。

## 上下文体量

- [ ] 根规则可以快速扫描。
- [ ] 模块规则只在进入对应目录时加载。
- [ ] 长文档有摘要或 Section Index。
- [ ] 当前任务只加载相关 Active 事项。

## 公开安全

- [ ] 没有公司、平台、仓库或人员标识。
- [ ] 没有真实接口、域名、凭证或生产数据。
- [ ] 示例路径和数据完全合成。
- [ ] 没有直接复制的非公开文档或代码。
