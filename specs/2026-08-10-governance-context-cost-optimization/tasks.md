# Tasks：治理上下文成本归因与最小加载优化

## 执行规则

- 每个任务都关联 Spec 完成条件或 Plan 决策。
- 先完成归因和决策门，再修改代码或采用内容。
- 实验原始日志只保存在临时目录，公开产物只保存脱敏聚合结果。
- 不记录 Commit 日记，不自行提交、推送或归档。

## 任务

### T-01 建立静态成本盘点与实验基线

- 状态：`done`
- 依赖：无
- 对应：`AC-001` / Plan“当前证据与假设”
- 输入：已归档对照、真实样本治理候选、Resolver 实现、项目 Skill 安装集合。
- 动作：量化规则、Knowledge、Active Spec、Skill 元数据/正文和 Resolver 输出；固定普通有界任务与可比条件。
- 产物：`research.md` 的静态盘点和实验设计。
- 验证：每项指标可从文件或只读命令复算，推断单独标识。
- 阻塞条件：真实样本状态变化导致无法复现既有候选。

### T-02 执行单变量只读成本实验

- 状态：`done`
- 依赖：`T-01`
- 对应：`AC-002`、`AC-007`
- 输入：`current-full`、`selective-skills`、`load-plan-stop` 三个临时变体。
- 动作：每个变体至少运行两次独立只读会话，汇总输入/输出、工具批次、治理读取类别和行为结果。
- 产物：`research.md` 的脱敏归因矩阵。
- 验证：同模型、Prompt、源码 revision、沙箱和重复次数；真实样本前后状态不变。
- 阻塞条件：Agent Host 无法提供可比较计量或只读边界。

### T-03 完成决策门

- 状态：`done`
- 依赖：`T-02`
- 对应：`AC-003`
- 输入：归因矩阵。
- 动作：判断是否存在方向一致且不损害行为的收益，确定改 Resolver、采用内容、安装边界或停止实现。
- 产物：`plan.md` 最终决策、`tasks.md` 后续范围。
- 验证：新增产物、消费者、验证和删除条件均明确；无收益时不创建空实现。
- 阻塞条件：变体结果冲突且无法通过一次限定补充实验解释。

### T-04 实施最小优化

- 状态：`done`
- 依赖：`T-03`
- 对应：`AC-003`、`AC-004`、`AC-005`
- 输入：已通过的决策门；每次普通规划都会读取的 Specflow 主入口。
- 动作：不修改 Resolver、Distribution 或项目模板；把 Specflow 主文件中的终态实现细节收敛为既有 Reference 的按需路由，并增加普通规划不展开终态材料的行为 Case。
- 产物：范围内代码、Skill、模板或文档变更。
- 验证：相关单元测试及内容行为复核通过；未新增通用 Runtime。
- 阻塞条件：收益要求破坏兼容、安全或项目领域语义。

### T-05 执行行为与成本双回归

- 状态：`done`
- 依赖：`T-04`
- 对应：`AC-004`、`AC-005`、`AC-006`、`AC-007`
- 输入：优化候选、相同任务矩阵、Bootstrap 7 Case Replay。
- 动作：复跑普通任务和显式 readiness 审计，运行 Replay、Harness 与仓库门禁。
- 产物：脱敏回归结果。
- 验证：行为不退化，成本结论保留噪声和未改善项。
- 阻塞条件：任一阻塞级行为回归或仓库检查失败。

### T-06 同步文档与 Knowledge Projection

- 状态：`done`
- 依赖：`T-05`
- 对应：`AC-008`
- 输入：最终实现和验证结果。
- 动作：仅投影稳定事实，更新能力地图和 Knowledge Projection。
- 产物：`knowledge-projection.yaml`、必要的 Knowledge/Docs 变更。
- 验证：Projection Plan/Apply/Verify、Knowledge Check 通过。
- 阻塞条件：结果不足以形成稳定长期结论。

## 验收任务

### V-01 完成条件复核

- 状态：`done`
- 动作：逐项检查 AC-001～AC-008，生成最终 `validation-report.md`。
- 产物：`validation-report.md`。
- 验证：完成项均有执行观察或交叉验证，未完成项不会标记为完成。

## 状态说明

- `pending`：尚未开始；
- `in-progress`：正在执行；
- `blocked`：缺少输入、授权或依赖；
- `done`：动作和验证均完成；
- `skipped`：经明确决策不再执行，并记录理由。
