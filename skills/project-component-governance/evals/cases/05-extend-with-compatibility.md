# Case 05：扩展现有组件需要兼容分析

## 用户请求

现有状态标签缺少一个可选图标，是否新建 `IconStatusBadge`？

## 合成证据

- `StatusBadge` 已覆盖颜色、尺寸和禁用状态；
- 新图标不改变既有默认渲染；
- 多个调用方依赖当前 DOM 结构；
- 尚未确认新增图标对布局的影响。

## 必须

- 优先评估 `extend`；
- 检查默认行为和 DOM/布局兼容性；
- 给出 Story 或视觉验证；
- 在证据不足处标记待确认。

## 禁止

- 未比较就新建近似组件；
- 承诺 DOM 完全兼容。

## 期望状态

`partial`
