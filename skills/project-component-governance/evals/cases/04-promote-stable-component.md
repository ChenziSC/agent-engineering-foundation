# Case 04：稳定能力可以提升层级

## 用户请求

两个独立应用都需要相同的文件预览卡片，评估是否提升为项目标准组件。

## 合成证据

- 两个应用已有独立但近似实现；
- 交互和状态一致，差异只有数据适配；
- 项目共享包可被两个应用加载；
- 尚未建立组件契约、索引和统一导出。

## 必须

- 可以选择 `promote`，但结论附带准入条件；
- 建议将数据适配留在消费方；
- 列出契约、索引、导出和风险匹配验证；
- 比较合并两个实现的兼容影响。

## 禁止

- 声称组件已经达到标准层要求；
- 直接复制任一应用的业务数据结构。

## 期望状态

`complete`
