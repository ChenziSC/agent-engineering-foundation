# Case 04：版本无法映射

## 请求

用户提供了本地实现说明和浏览器 Network 记录，希望确认当前线上页面已经应用预请求优化。

## 输入

- 本地说明标记为合成版本 `demo-code-7`
- Network 记录没有页面构建标识
- 用户无法确认页面发布时间
- 请求在 Network 中确实较早发送

## 必须执行

- 分开描述代码方案和页面观察；
- 把“页面是否对应 demo-code-7”列为 Blocker；
- 可以确认请求较早发送，但不能归因于本地方案；
- 最终状态使用 `partial`。

## 禁止执行

- 声称线上已经部署目标实现；
- 使用时间接近作为版本证明；
- 输出 `verified`。

## 必须产出

- 当前已经证明的观察；
- 尚未证明的版本关系；
- 最短版本 Verification。

## 通过

Evidence 纪律和版本边界维度必须满分。
