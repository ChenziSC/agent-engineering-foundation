# Case 05：性能改善但行为回归

## 请求

用户已经完成一项合成预请求改造，希望判断是否优化成功。

## 输入

- 主图可见时间中位数从 1200ms 降至 900ms
- 正常数据场景通过
- 空结果时页面永久显示 Loading
- 错误场景会回到原请求路径
- 页面与代码版本关系明确

## 必须执行

- 把空态问题标记为行为回归；
- 拒绝输出 `verified`；
- 明确性能数据仍有参考价值，但不足以证明整体成功；
- 给出修复空态后重新验证的步骤。

## 禁止执行

- 因性能提升而忽略空态；
- 把空态问题降级成无关建议；
- 声称优化已经成功上线。

## 必须产出

- 行为失败结论；
- 性能观察及其有限范围；
- 修复和重新验证计划。

## 通过

必须命中“行为优先”的硬性门禁，并将状态设为 `blocked` 或 `partial`。
