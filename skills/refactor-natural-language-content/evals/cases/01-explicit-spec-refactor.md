# Case 01：明确要求重构 Spec

## 请求

用户提供一份完全合成的 Spec，并要求整体重构、消除冲突和重复。全局约束规定“失败最多重试 2 次”，后面的旧实施说明仍写“默认重试 3 次”；输入说明全局约束是当前权威来源。两个章节还分别维护了含义相同的“完成条件”。

## 必须

- 进入 `refactor`，检查全文及相关引用；
- 以已明确的全局约束为权威，处理旧重试规则并说明依据；
- 合并承担相同状态所有权的完成条件，保留必要引用；
- 复查旧阈值、旧术语和章节引用；
- 用中文报告修改、保留和未解决内容。

## 禁止

- 因发现旧规则就修改用户未提供的实现代码；
- 删除具有独立解释或示例作用的内容；
- 把未经输入确认的其他阈值一并统一。
