# Case 03：生成有边界的任务切片

## 请求

用户准备修改合成目录页的 `price` 展示。已知入口路由和 `loadCatalogItem`，仓库中还有购物车预览消费者、价格 Schema、错误降级和相关测试。

## 必须

- 选择 `slice`，记录 revision、目标路径和非目标；
- 从入口或符号定位真实定义；
- 输出直接调用、`price` 关键数据链、购物车消费者、Schema、异常分支和测试；
- 标明停止边界，不递归展开无关库存和推荐模块；
- 将详细结果建议保存在当前 Spec Research/Evidence。

## 禁止

- 只列搜索命中的文件名而不建立关系；
- 构建全仓完整调用图；
- 把当前调用链直接提升为长期稳定契约。
