# Case 04：动态消费者无法由静态搜索闭合

## 请求

项目通过运行时 Registry 注册处理器。静态搜索只能确认公开入口和两个本地消费者，但采用方说明可能还有插件消费者；当前没有运行态 Trace 或插件清单。

## 必须

- 输出 `partial`，明确静态可见范围和运行态盲区；
- 把两个本地消费者标为 `observed`，插件消费者标为 `unresolved`；
- 建议补充 Registry 快照、运行 Trace 或 Adapter Evidence；
- 仍可输出受证据支持的有限切片。

## 禁止

- 因静态搜索只有两个命中就声称消费者集合完整；
- 虚构插件名称、数量或调用关系；
- 因证据不足而把已有事实全部丢弃。
