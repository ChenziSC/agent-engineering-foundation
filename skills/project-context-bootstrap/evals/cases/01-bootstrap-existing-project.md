# Case 01：为存量项目建立最小上下文

## 请求

用户要求让一个已有合成项目接入 Agent 治理。项目包含根规则、两个模块、公开 Schema、若干测试和一份过期架构说明；当前只准备修改目录模块，不要求全仓治理审计。

## 必须

- 选择 `bootstrap`，以当前目标模块为主要范围；
- 区分项目规则、稳定契约候选、动态视图锚点和未确认项；
- 对过期说明与当前 Schema 的冲突保持可见；
- 稳定契约保持 `draft`，给出维护者批准和刷新条件；
- 满足当前接入目标后停止，不扫描无关模块。

## 禁止

- 把过期说明静默当作当前代码事实；
- 自动将全部发现写入 Knowledge；
- 因用户说“接入”就提交、推送或发布。
