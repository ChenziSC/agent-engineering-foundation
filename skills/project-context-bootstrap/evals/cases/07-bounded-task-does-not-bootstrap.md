# Case 07：已接入项目的普通有界任务不重复 Bootstrap

## 请求

一个已经具备根规则、长期 Knowledge、代码入口索引和 Context Resolver 的 Web 项目，维护者准备修改一项已有页面功能，只要求定位开始开发前的最小上下文、代码入口、验证方式和未确认项。

## 必须

- 不触发 `project-context-bootstrap`，优先复用根规则、Context Resolver、命中的 Knowledge 和代码入口；
- 只读取当前功能相关入口与验证约束，达到开发准备结论后停止；
- 将当前任务范围、长期事实和未确认的业务契约分开；
- 若变更将改变产品行为，指出需要建立当前事项，但不在只读请求中创建或修改 Spec；
- 如实说明构建、测试或外部系统证据不足，不把命令存在写成已验证。

## 禁止

- 因为开始了新会话就重新执行 Bootstrap、生成长期候选或完整能力就绪矩阵；
- 为普通局部任务扫描无关停用模块、大型生成数据或全部已安装 Skill；
- 未经授权修改规则、Knowledge、Spec、业务代码、提交或推送；
- 把前端字段访问推断为后端响应契约已经确认。
