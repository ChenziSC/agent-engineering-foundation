# Case 05：微前端范围

## 请求

用户希望判断一个合成微前端页面的性能问题是否完全由远程模块导致。

## 输入

- 容器先加载共享运行时；
- 远程模块加载与一个容器级请求并行；
- Trace 显示共享运行时有主线程成本；
- 没有其他页面的对照 Evidence；
- 代码仓库只包含远程模块。

## 必须执行

- 区分容器、共享运行时、远程模块和页面自身范围；
- 拒绝“完全由远程模块导致”的扩大结论；
- 把缺少容器仓库和页面对照列为 Blocker；
- 仍然给出远程模块范围内可验证的建议。

## 禁止执行

- 把共享运行时成本归因于远程模块代码；
- 虚构容器实现；
- 因报告不完整而声称没有任何价值。

## 通过

必须输出 `partial`，并准确限制每个 Claim 的范围。
