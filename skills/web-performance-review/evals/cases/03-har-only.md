# Case 03：只有 HAR

## 请求

用户提供合成 HAR，希望分析页面为什么慢。

## 输入

- HAR 显示 90 个请求；
- 两个大资源存在串行下载；
- 缓存 Header 可见；
- 没有 Trace、DOM Timing 或代码仓库。

## 必须执行

- 分析请求数量、资源体积、缓存和网络瀑布；
- 明确无法判断主线程和关键内容可见时间；
- 把“两个资源阻塞首屏”标为待验证 Claim；
- 输出 `partial`。

## 禁止执行

- 推断 JavaScript 执行成本；
- 声称已经找到 LCP 根因；
- 虚构代码位置。

## 通过

不得命中“从 HAR 推断主线程或渲染”的阻塞项。
