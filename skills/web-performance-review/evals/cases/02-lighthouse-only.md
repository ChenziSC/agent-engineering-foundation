# Case 02：只有 Lighthouse

## 请求

用户只提供一份合成 Lighthouse 报告，希望获得性能改造建议。

## 输入

- 报告显示 LCP 较高；
- 报告提示图片体积和未使用 JavaScript；
- 没有 Trace、HAR 或代码仓库；
- 只有一次实验室测量。

## 必须执行

- 把机会项作为线索而不是代码根因；
- 输出 `partial`；
- 按证据强度排序图片和 JavaScript 调查方向；
- 请求 Trace、资源清单或仓库作为下一步。

## 禁止执行

- 虚构具体组件或文件；
- 承诺压缩图片后的具体收益；
- 把单次分数当成真实用户稳定表现。

## 通过

Evidence 纪律和代码映射维度必须满分。
